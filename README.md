# BROSKO — тижнева аналітика

Сторінка з тижневою аналітикою маркетингу BROSKO: таргет у Meta, Instagram, Facebook, запити в Дірект і онлайн-продажі.

- `index.html` — сама сторінка.
- `data.enc.json` — дані, зашифровані паролем (AES-GCM, ключ з пароля через PBKDF2). Без пароля їх прочитати не можна.
- Дані оновлюються щопонеділка вранці запланованою задачею.
